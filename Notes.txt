****Day 1 - What is Machine Learning?****

->Formal Definition
It is a field of computer science that uses statistical techniques to give computer systems the ability to "learn" with data, without being explicitly programmed.

ML is all about learning about data.

What is Explicitly Programming?
In which you write code for every scenario(To handle that scenario)
But in ML we don't do that, We got some data and algorithm we apply that algorithm to the data which explores the data and identify patterns. And once it do this, we give it new data(Test Data) and on the basis of what the data has learn it gives us some output.

->In what scenarios ML can be helpful to us??
We cannot perform few things using programming, we cannot write cases for everything. In this scenarios ML is helpful
(i)Email spam classifier(Email spam or not)
This can be done using software developer techniques(Traditional Programming)(Writing cases) but it will be too long because we have to write cases like if a mail contains "discount"(more than 3 times) than it will be spam.

For example:-
You have created cases for finding an email whether it is spam or not. Suppose 1 test case is this:- If word "huge" appears more than 3 times than it is a spam email.
But now what the advertising companies do??
They can replace the "huge" -> "Big", now you need to update your logic again so that your code can runs efficiently.
But what ML does is? It learns from data, if data changes then it will automatically get reflected in the logic

(ii)Dog is present in the picture or not
If you will use Traditional programming you have to write 'n' number of test cases such as on the basis of color, breeds, height and other characteristics.


->What is Data Mining??
Data analysis -> We find hidden information in the data by plotting graphs.

But sometimes there is more hidden information which cannot be find by just plotting the graphs.

So what is Data Mining -> We train a model on the data just like an email spam classifier and if you are able to extract important data from that information that is known as Data Mining.

->History??
Machine Learning has existed since the 1950s, but it saw rapid growth after 2010 due to the availability of large datasets, powerful computing (especially GPUs), and advances in algorithms like deep learning


->AI vs ML vs DL Notes

1. AI (Artificial Intelligence)
- Uses rule-based systems (IF-ELSE)
- Example: IF "FREE" → spam
- Limitation:
  - Rigid rules
  - Not scalable for complex problems

2. ML (Machine Learning)
- Learns patterns from data
- Example: Train on spam/not spam emails
- Key Point:
  - Requires feature engineering (keywords, edges)
- Limitation:
  - Hard to design features
  - Struggles with complex data

3. DL (Deep Learning)
- Uses neural networks
- Learns patterns + features automatically
- Example: Understands context in emails/images
- Advantage:
  - No manual feature engineering
  - Works well on images, speech, text
- Limitation:
  - Needs large data + high computation

Examples:

1. Spam Detection
- AI: Rule "FREE" → spam (fails)
- ML: Learns from emails (better)
- DL: Understands context (best)

2. Self-Driving Cars
- AI: Rule-based detection (fails)
- ML: Uses features (limited)
- DL: Detects objects automatically (best)


Final Line:
AI = rules
ML = learns from data
DL = learns data + features automatically


****Types of Machine Learning****
(i)Supervised -> Regression and Classification
(ii)Unsupervised -> Clustering, Dimensionality reduction, Anomaly detection and Assosication
(iii)Semi Supervised
(iv)Reinforcement


->Supervised Learning
Suppose we have Input and output for a data and now we need to predict for a new input what will be output for that input. This is known as Supervised Learning.

For example:-
IQ|CGPA|Y/N(Placement)
87|7.1|Y
90|7.5|Y
60|5.2|N

We have both Input(IQ, CGPA) and Output(Y/N(Placement)). Now the task for the algorithm will be to create a mathematical relationship between Input and Output. So that if a new data comes in it can easily get predicted.

There are two types of data:-
(i)Numerical
(ii)Categorical

Regression -> Ouput Column is Numerical
For example:- IQ|CGPA|PACKAGE

Classification -> Output Column is Categorical
For example:- IQ|CGPA|Y/N(Placement)


->Unsupervised Learning
When we don't have output column, we use this learning.
It creates patterns (groups) and from visiualizing that patterns we can see what group of people are following the same thing kind of.
(i)Clustering
Creates patterns/Clusters
(ii)Dimensionality reduction(PCA)
Suppose there are many columns, we will not be able to plot the patterns. In this case we tend to remove the unnecessary columns which don't hold as much information OR we can create a new column by combining multiple columns
(iii)Anomaly Detection
Like finding the outliers(That are different from the other points)
(iv)Assosication Rule Mining
It involves discovering new rules by analyzing the data.
For example:-
In a shopping mart, people often buy bread with butter. So we can put that two things together. So that the sales can be improved and people will be at ease finding these two items.


->Semi-Supervised Learning
Partially supervised and partially Unsupervised.
Output columns is very expensive -> At the end who will tell whether in the image it is a dog or cat, Human being will tell only. Labelling which is done, it is done by the humans only and it takes a lot of effort.
We can get the INPUT column from anywhere but what about the OUPUT column(The data which is inside the photo, To do this we have do it manually and it will require more human efforts, time and money)

Solution:-
What if we label only 1-2 points and rest automatically gets labelled. This is the core idea behind semi-supervised learning.

For example:-
In Google Photos, the system first uses unsupervised learning techniques to cluster similar faces together without knowing their identities. After that, when a user labels a few images (e.g., assigning a name to a face), the system uses this small amount of labeled data along with the large unlabeled dataset to recognize the same person in other images. This is an example of semi-supervised learning, where both labeled and unlabeled data are used together.

->Reinforcement Learning
Reinforcement Learning is a type of machine learning where an agent learns by interacting with an environment and improving its actions based on feedback in the form of rewards or penalties. The goal is to maximize the total reward over time.

For example, a game-playing AI learns which moves are good or bad by receiving rewards for winning and penalties for losing.


****Batch Machine Learning (Offline vs Online)****
(i)Offline learning (Batch Machine Learning)
-It states that the entire dataset was trained on the model at once.
-After training it is deployed on the server. Afterwards when new data comes it gives prediction for that data.

Disadvantages:-
(i)No real time updates
(ii)Time consuming (If the data is large)

For example:-
We have made a model and deployed it on the server related to Email Spam classifier using this technique. Now the data on which the model was trained would not be remain same, it can get update, new data can comes in and it can get false results. So to solve this problem, User again trained the data (Old + New) and again deployed it on the server.

Note:-
-And also most of the Data Scientists/ ML engineers make a rule that the system will automatically trained the new data along with the old data after 24hrs/ 3days/ 1week

(ii)Online Machine Learning
In this we do Incremental learning using mini batches of the data where you train your model sequentially using mini batches.
Since batches are small, we can perform the training on the server itself, it will not cost that much.

->How it works??
(i)Model is trained initially (basic training)
(ii)New data arrives (one-by-one or in small batches)
(iii)Model updates its weights instantly
(iv)No full retraining needed

Example:-
YouTube recommendation system. When you see a particular video, your feeds gets automatically changed related to that content where you see more content related to that.

-Advantages
(i)Adapts quickly to data drift
(ii)No need for full retraining
(iii)Works well with large/streaming data

-Disadvantages
(i)Can learn wrong patterns if bad data comes
(ii)Harder to debug
(iii)Needs careful monitoring


Data Drift -> The pattern of the data changes over time

->When to use Offline/ Online Learning
When the pattern of the data changes over time(Data Drift). At that time you must use Online learning.
Example:-
Stock Exchange, Ecommerce Platforms

Same

->Learning Rate(Important Point)
When you will use ONLINE LEARNING, you need to decide learning rate. It means that how much the model updates its knowledge from new data.
It must not be too high because it can forgot the previous patterns.

Learning rate = speed/strength of learning, not timing

->Out of core learning
It is a technique used when the dataset is too large to fit into RAM, so the model is trained by loading data in small chunks (batches).

-How it works??
(i)Load a small chunk of data from disk
(ii)Train the model on that chunk
(iii)Discard it from memory
(iv)Load next chunk
(v)Repeat until full dataset is processed

(iii)Non Representative Data
It means that your data was not complete and you still trained the model.

It means that your data does not properly represent the real-world population 
and you still trained the model.

Example: Suppose you have trained your Linear Regression model on 
non-representative data. It gives a line of good fit, but in reality, since 
the data was not representative, the line plotted by the model is wrong.


1. SAMPLING BIAS (Wrong Data Collection)

Real-World Example: Suppose you are conducting a survey for who will win the 
T20 World Cup. You have conducted the survey in India only. People in India 
will mostly support India, which shows that our data is not representative. 
We should conduct the survey globally. 

This is known as Sampling Bias (poor representation of data due to wrong 
data collection).

Fix: Conduct survey in ALL countries (change your collection method)


2. SAMPLING NOISE (Random Variation)

Now suppose you conduct the survey in different countries randomly, but still 
most people say India will win due to chance. 

This is known as Sampling Noise (error due to randomness).

Fix: Collect more data (larger sample size reduces random error)

****Tensors****
It is a data structure(Way to store the data)

Why Tensor??
Libraries like Tensor Flow, they use the basic data structure which is Tensor. Even if you are dealing with any problem related to ML and DL, you have to deal with the Tensor.

Tensor -> Way to store data
More breakdown → It is a container which stores numbers. Generally, tensors store numerical data. Storing characters or strings is possible, but in ML and DL it is very rare because models mostly work with numbers.

Vectors/ matrix -> Also use tensor

->Types of tensors based on Dimension
(i)0D Tensors/ Scalar
If you are storing a single number this is known as Scaler.
0D means -> For this particular tensor it has zero Dimension.

nd array = TENSOR


(ii)1D Tensors/ Vector
[1, 2, 3, 4] -> 1D Tensor, Vector, 1D Array, nDim = 1

Axis = Dimension
No. of axes = rank/ Dimension

[1, 2, 3, 4] -> It is a 1d Tensor or we can say it is a vector. But how many Dimension it has for the vector(It will be number of elements inside the 1D Tensor). For example:-
[1, 2, 3] -> 3D vector
[1, 2] -> 2D vector

(iii)2D Tensors/ Matrices
If we combine multiple vectors/ 1D tensors we get 2D tensors
a = [1, 2, 3], b = [1, 2, 3]
[[1, 2, 3], -> 2D tensors
 [1, 2, 3]]


->Rank, Axes and Shape
Rank = Axes -> No of Dimension in the Tensor
Shape = ((No of rows), (No of columns))

->CSV Files
You can import the data from the CSV files in two ways:-
(i)File in in local machine (pd.read_csv)
(ii)Fetch CSV file from an URL (Through requests)


->Parameters in read_csv()
(i)sep parameter
By default read_csv() has separater "," which is for CSV files only. But what if the data is in the form of TSV(Tab Separated Values), use "sep" parameter in this case.
(sep = '\t')

(ii)names parameter
This parameter is used when column names are not given in your dataset. You can provide an array of list.

For example:-
pd.read_csv('movie_titles_metadata.tsv', sep = '\t',names = ['sno', 'name', 'release_year', 'rating', 'votes', 'genres'])


(iii)index_col parameter
By default, pandas create an index column whenever you load a dataset.
You can replace that column with your column that exists in your dataset with the help of index_col parameter

For example:-
pd.read_csv('aug_train.csv', index_co l= 'enrollee_id')

(iv)header parameter
It is used when in your dataset your first row is not about column names but your column names exist in your dataset. And you want to fix this. For example:-

pd.read_csv('test.csv', header=1)
header = 1 cotains column names, so finally the column names would be visible instead treating it as a row.

(v)use_cols parameter
Suppose when you are loading a dataset but you only want specific columns to work upon. For example:-

pd.read_csv('aug_train.csv', usecols = ['enrollee_id', 'gender', 'education_level'])

(vi)skip_rows parameter
With the help of this function you can skip rows. It will not be loaded in your df. For example:-

pd.read_csv('aug_train.csv', skiprows = [0, 1])

(vii)nrows parameter
It will restrict the number of rows
You will load that particular number of rows only in your df.
For example:-
pd.read_csv('aug_train.csv', nrows = 100)
